TENTANG SISTEM

Mengenal Absensi QR

Absensi QR merupakan sistem pencatatan kehadiran mahasiswa menggunakan teknologi QR Code untuk membantu proses absensi perkuliahan menjadi lebih efektif dan efisien.

FITUR UTAMA

Kemudahan dalam Satu Sistem

Mendukung pengelolaan kehadiran mahasiswa secara digital.

Scan QR Code

Mahasiswa dapat melakukan absensi dengan memindai QR Code menggunakan smartphone.

Data Terintegrasi

Data kehadiran tersimpan secara terpusat menggunakan database online.

Laporan Kehadiran

Admin dapat memantau dan melihat rekap kehadiran mahasiswa.
